# Changelog

What changed in each release of Drawbridge, newest first. A release's notes on GitHub are its
section here, so each section is written for the admin who is about to upgrade: what they need to
know first (anything an upgrade changes or asks them to do), then what changed.

A release is made from a pull request that adds its section (docs/PLAN.md §11.1). The heading is
the version with its `v`, as in `## v1.0.0 - 2026-10-05`, and a version without a section can't be
released.
